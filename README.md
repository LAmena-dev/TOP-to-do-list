# To Do List
A [JavaScript practice project emulating a to do list.](https://www.theodinproject.com/lessons/node-path-javascript-todo-list) It makes use of Web Development technologies and Webpack to bundle modules.

## Technology Used
* HTML
* CSS
* JavaScript
* Webpack

## Features
- A General tab and the ability to create more tabs containing their own tasks.
- A task search to search based on task name, and a task filter to filter based on priority and status.
- A task creation feature which allows a task name, description, due date, and task priority which have their own border colors based on priority. These tasks can be edited and removed.
- The use of localstorage to store tabs and tasks.
